# Отчёт по продажам собирается 40 минут: найти причину

Задача: `db-slow-report`. Версия БД: **0**. Статус: **published**.

## Вывод по полноте

Условие достаточно для плана диагностики, но не для установленного диагноза и доказанного ускорения. Наличие DATE в фильтре — гипотеза, а не доказательство причины всех 40 минут.

## Открытые вопросы

Для каждого вопроса нужны ответ, источник и решение: дополнить условие / оставить частью задания / разрешить явное допущение. Ответы пока не получены.

### db-slow-report-Q01 · P0 · Данные

**Вопрос пользователя:** Можно получить полный SQL с обоими подзапросами и реальными значениями параметров?

**Зачем нужен ответ:** Упрощённого пересказа недостаточно для проверки повторных сканирований, JOIN и корректности переписывания.

**Предлагаемый адресат:** Разработчик. **Статус:** открыт.

### db-slow-report-Q02 · P0 · Данные

**Вопрос пользователя:** Как выглядят DDL orders, order_items, products, stores: типы, PK/FK, все индексы, партиции и ограничения?

**Зачем нужен ответ:** Индекс только по order_items не описывает доступ к orders; тип created_at влияет на границы дат.

**Предлагаемый адресат:** DBA. **Статус:** открыт.

### db-slow-report-Q03 · P0 · Данные

**Вопрос пользователя:** Есть ли план выполнения с фактическими строками, временем и буферами для медленного запуска? Где его безопасно получить?

**Зачем нужен ответ:** Нужно отличить плохие оценки, чтение диска, сортировки и многократные выполнения; диагностический запуск тоже создаёт нагрузку.

**Предлагаемый адресат:** DBA. **Статус:** открыт.

### db-slow-report-Q04 · P0 · Данные

**Вопрос пользователя:** Что происходило с CPU, RAM, дисковыми задержками/IOPS, свободным местом, сетью, блокировками и активными сессиями в 06:00? Есть ли лимиты контейнера?

**Зачем нужен ответ:** Позволяет проверить инфраструктурную причину. Фраза «с инфраструктурой всё хорошо» без временного интервала и метрик не исключает её.

**Предлагаемый адресат:** Эксплуатация / DBA. **Статус:** открыт.

### db-slow-report-Q05 · P0 · Данные

**Вопрос пользователя:** В эти 40 минут входят ожидание очереди, SQL, передача результата, генерация Excel и отправка? Есть разбивка по этапам?

**Зачем нужен ответ:** Ускорение SQL не решит задержку, если основное время тратится на выгрузку или ожидание.

**Предлагаемый адресат:** Разработчик / эксплуатация. **Статус:** открыт.

### db-slow-report-Q06 · P0 · Правило

**Вопрос пользователя:** В каком часовом поясе определены «вчера» и прошлая неделя? Какие статусы, отмены, возвраты и скидки входят в выручку?

**Зачем нужен ответ:** Границы полуинтервала и эквивалентность результата нельзя определить только по имени created_at.

**Предлагаемый адресат:** Продажи / финансовый аналитик. **Статус:** открыт.
