# Таблица заявок «как в Excel» → нормальная схема

Задача: `db-normalization`. Версия БД: **0**. Статус: **published**.

## Вывод по полноте

Для концептуальной декомпозиции данных достаточно, но доказать нормальные формы, написать полный маппинг и гарантировать перенос без потерь без DDL и зависимостей нельзя.

**Вопрос пользователя:** Можно получить все 60 колонок с типами, ограничениями, текущими ключами, примерами строк и используемыми запросами?

**Зачем нужен ответ:** Названий групп полей недостаточно для доказательства функциональных зависимостей и полного переноса.
