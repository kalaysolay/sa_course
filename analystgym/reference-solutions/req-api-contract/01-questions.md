# Контракт API для мобильного приложения: версии, пагинация, ошибки

Задача: `req-api-contract`. Версия БД: **0**. Статус: **published**.

## Вывод по полноте

Для проектного контракта данных достаточно, но отсутствуют реальные типы операций, текущие клиенты и согласованные НФТ. Пример должен явно отделять предложенные поля от фактов.

## Открытые вопросы

Для каждого вопроса нужны ответ, источник и решение: дополнить условие / оставить частью задания / разрешить явное допущение. Ответы пока не получены.
