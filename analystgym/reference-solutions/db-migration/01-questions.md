# Миграция 200 млн строк без простоя: план и риски

Задача: `db-migration`. Версия БД: **0**. Статус: **published**.

## Вывод по полноте

Есть конфликт формулировок: разделение одной строки на несколько таблиц не допускает буквального построчного равенства. Нужна логическая эквивалентность, особенно для неконсистентных данных.

## Открытые вопросы

Для каждого вопроса нужны ответ, источник и решение: дополнить условие / оставить частью задания / разрешить явное допущение. Ответы пока не получены.
