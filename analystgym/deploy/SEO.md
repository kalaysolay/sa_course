# Поисковая доступность и измерение воронки

## Что отдаёт приложение

`/robots.txt`, `/sitemap.xml`, главная, `/practice.html`, `/catalog.html` и
`/task.html?id=…` доступны без входа. Карта автоматически учитывает публикацию
и снятие задач. В HTML карточки есть публичное условие; эталоны не публикуются.
Редактор и отправка решения требуют JavaScript. Отдельные SEO-копии задач не нужны.

Canonical, Open Graph, sitemap и JSON-LD используют `APP_SITE_BASE_URL`.
На production он должен быть `https://analystgym.pro` (без пути и завершающего `/`).
Нельзя строить canonical по присланному клиентом Host. Служебные страницы
помечены X-Robots-Tag; отсутствие в sitemap не заменяет авторизацию.
Только серверная сборка обеспечивает эти возможности; статическое демо не является production-сайтом.

## Метрика

Счётчик ещё не создан. До настройки `ANALYTICS_METRIKA_ID` внешняя аналитика
не загружается. Создайте счётчик на `https://metrika.yandex.ru/` для домена
analystgym.pro; укажите его числовой ID в окружении приложения. В локальном
compose это `deploy/.env`. На текущем VPS env задаётся root в
`/etc/analystgym-deploy/compose.json`, `services.app.environment`; сохраните
остальные настройки и перезапустите приложение штатным способом. Не публикуйте
содержимое окружения: там есть секреты. Сам ID счётчика публичный.

Создайте цели типа JavaScript-событие:

| ID | Значение |
|---|---|
| practice_open | Открыта страница практики |
| catalog_open | Открыт каталог |
| task_open | Открыта задача |
| solution_submitted | Сервер подтвердил отправку решения |
| review_open | Открыт результат попытки; возможна заглушка |
| waitlist_open_pro | Открыта форма Pro |
| waitlist_open_team | Открыта форма Team |
| waitlist_success_pro | Сервер принял новую заявку Pro |
| waitlist_success_team | Сервер принял новый запрос Team |

Цели не означают покупку. Дубликаты и локальные черновики не дают успешную
заявку. Открытие результата не означает получение полезного ИИ-ревью.
Отчёты смотрите по уникальным посетителям и источникам, а не только числу событий:
повторное открытие результата или восстановление отправки может дать повтор события.
На публичных страницах сохраняются корректные UTM-параметры, но не токены,
произвольные параметры, hash, контакты или текст решения. Webvisor, карта кликов
и автоматическое отслеживание ссылок отключены. Блокировщик аналитики не мешает продукту.
В личном кабинете и формах входа счётчик не подключается.

## После выпуска

1. Проверить анонимно robots/sitemap (200), опубликованную задачу (200 с условием
   в исходном HTML) и несуществующую (404). Проверить canonical на HTTPS-домен.
2. Создать проекты в Яндекс Вебмастере и Google Search Console, подтвердить домен
   через DNS у регистратора. Отправить `https://analystgym.pro/sitemap.xml`.
   Проверить URL главной, каталога и нескольких задач инструментами кабинетов.
3. После подключения Метрики пройти путь каталог → задача → реальная практика,
   проверить получение событий. Не отправлять фиктивные заявки в production.
4. Проверить список гипотез запросов через Wordstat: прежние 44 фразы не были
   подтверждены частотностью. Затем выбрать темы самостоятельных полезных разборов.

Доступ к кабинетам и DNS требуется владельцу. Код не создаёт аккаунты в поисковых
сервисах и не гарантирует индексацию, позиции или трафик.

Основания: [Google о JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics),
[карты сайта](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap),
[Метрика reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal),
[очистка HTML jsoup](https://jsoup.org/cookbook/cleaning-html/safelist-sanitizer).
