# Скилл: ревью проектного артефакта (review-project-artifact)

## Назначение

Проверить, что proposed/approved артефакты соответствуют passport и не ломают факты Compliance.

В lean — self-check автора + проверки finalize. Отдельный reviewer — только при блокирующем конфликте.

## Смотреть

- все `expected_artifacts` присутствуют;
- нет выдуманных project facts;
- пути согласованы с вкладкой «Документация» трекера;
- canonical merge не сделан «тихо», если auto-merge выключен.
