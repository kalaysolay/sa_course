# Скилл: редакторское ревью (review-editorial)

## Назначение

Проверить форму лекции по `course-style.md` (lean: часть `learning` в `03-lean-review`).

## Отклонять, если

- доминируют списки/таблицы вместо прозы;
- нет связного сценария и переходов;
- нет визуальной модели там, где она обязательна;
- техническая нотация без расшифровки для новичка.

## Результат

Issues с кодами вроде `outline_like_lecture`, `list_dominated_body`, `table_without_narrative`, `missing_transitions` — в `learning.json`.
