# Скилл: предметное ревью (review-subject)

## Назначение

Проверить фактическую корректность и опору на источники (lean: часть `content` в `03-lean-review`).

## Критерии

- утверждения лекции не противоречат passport/source pack;
- нет выдуманных фактов Compliance;
- раздел `## Использованные источники` корректен, если источники реально использовались;
- блокируют только `critical` / `major`.

## Результат

`03-lecture/review-vN/content.json` (verdict APPROVED/REJECTED + issues).
