# Source Pack: PROF-ROLE

## Basis

This source pack uses author course materials, the local Compliance project manifest, and local mockups under `compliance_project_example`. External research is disabled for this Topic Passport.

## Compliance Project Context

The course project is an internal corporate Compliance system, not a KYC/customer-screening product.

The system automates:

- employee requests to the Compliance department;
- processing of those requests by Compliance officers;
- gift registration;
- employee declarations;
- declaration review;
- viewing registered gifts;
- viewing employees;
- dashboards and analytics for the Head of Compliance.

Employees use a portal and authenticate through company domain SSO. Compliance officers use a workspace for queues, request cards, declarations, gifts and employee lists. The Head of Compliance uses dashboards and reporting.

## Core Teaching Position

A system analyst helps a team turn a vague need into an agreed, testable description of how a system should behave. The analyst reduces uncertainty: clarifies goals, users, process, data, rules, statuses, exceptions, permissions, and acceptance criteria.

## Example Pool

Compliance: an employee submits a request to Compliance. The analyst clarifies request types, required fields, attachments, statuses, visibility, responsible officer, comments, history, notifications, and dashboard metrics.

Fintech: a payment service wants daily transfer limits. The analyst clarifies which operations count toward the limit, whether limits depend on user type, when the check happens, and what message the user sees when the limit is exceeded.

Edtech: an online school wants automatic certificates. The analyst clarifies completion criteria, retakes, certificate fields, delivery channels, and what happens when a student changes their name.

Marketplace: a marketplace wants product returns from the personal account. The analyst clarifies return windows, product categories, reasons, statuses, logistics, payments, and notifications.

Internal HR: a company wants vacation approval in an internal portal. The analyst clarifies roles, balance checks, approval steps, calendar integration, and cancellation rules.

## Review Caveats

The lecture must not describe the course Compliance project as customer onboarding, KYC, sanctions screening, or external-client activation. Those can be fintech examples, but the project itself is an internal employee Compliance portal.
