# Практика к уроку 4

## Задание 1. Первые вопросы

Сырой запрос: «Комплаенс-офицеры хотят удобную очередь обращений».

Сформулируйте:

1. 5 вопросов в BA-фокусе.
2. 5 вопросов в SA-фокусе.
3. 3 участника, с которыми нужно поговорить.

## Задание 2. Процесс и сценарий

Опишите простыми словами:

- процесс обработки обращения;
- один сценарий сотрудника;
- один сценарий комплаенс-офицера.

## Задание 3. Выберите артефакт

Для каждой ситуации выберите простой результат работы аналитика:

- список вопросов;
- описание процесса;
- сценарий;
- список требований;
- acceptance criteria;
- список открытых решений.

Ситуации:

1. Непонятно, какие статусы нужны обращению.
2. QA спрашивает, что проверять при пустом обязательном поле.
3. Руководитель комплаенс просит дашборд.
4. Сотрудники по-разному понимают слово «декларация».
