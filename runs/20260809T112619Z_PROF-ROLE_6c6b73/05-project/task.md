# Проектная практика: типовые задачи аналитика

Ситуация: в Compliance-системе нужно сделать удобную очередь обращений для комплаенс-офицеров.

Подготовьте первые заметки аналитика:

- 5 вопросов в BA-фокусе;
- 5 вопросов в SA-фокусе;
- список участников;
- простой сценарий обработки обращения;
- 3 открытых решения;
- 3 acceptance criteria.

Важно: Compliance-проект в курсе — внутренняя система компании. Не трактуйте его как KYC, проверку внешних клиентов или клиентский онбординг.
