# Практика к уроку 3

## Задание 1. Найдите зону пересечения

Для каждой ситуации отметьте, где BA-фокус, где SA-фокус, а где нужна совместная договоренность.

1. Сотрудник хочет видеть понятный статус обращения.
2. Комплаенс-офицер хочет быстро брать обращения в работу.
3. Сотрудник регистрирует подарок и не понимает, какие поля обязательны.
4. Декларация возвращается на доработку.
5. Руководитель комплаенс хочет дашборд по нагрузке отдела.

## Задание 2. Мини-договоренность

Возьмите одну ситуацию из списка и заполните шаблон:

- результат анализа;
- владелец результата;
- помощники;
- согласующие;
- артефакт, где фиксируем решение;
- открытые вопросы.

## Задание 3. Антипример

Перепишите плохую фразу в рабочую договоренность.

Плохая фраза: «Это не моя зона, пусть системный аналитик сам придумает статусы обращения».
