## Особые указания автора (11.11.2026)

- Особое внимание — качеству и понятности материала.
- Лекцию читают **не погружённые** в тему люди: каждому новому термину нужно доходчивое объяснение при первом же использовании.
- Разрешены (и приветствуются) понятные аналогии, если после них указана граница применимости (в духе course-style.md).

- Сквозной кейс — проект Compliance: в лекции должно быть упоминание и применение к нему.
- Приоритет исследований — первичные официальные источники (например, AWS API Gateway, Azure API Management, Kong Gateway, nginx); проверяйте доступность ссылок и фиксируйте evidence в source pack.
- Целевой уровень: базовый обзор (не энциклопедия). Ясность важнее полноты.
