## Задание 2

Возможное решение:

| Элемент | Решение | Комментарий |
| --- | --- | --- |
| Веб-портал сотрудника | MVP | Основной канал для создания обращений |
| Мобильное приложение сотрудника | Future scope | Нужно подтвердить частоту мобильных сценариев |
| Рабочее место офицера | MVP | Основная операционная зона |
| Дашборд руководителя | MVP или ранний post-MVP | Зависит от требований к управлению SLA |
| Десктопный клиент | Не включать | Нет явной причины установки на рабочие места |
| Админка справочников | MVP, если справочники меняются часто | Иначе можно начать с технической настройки |
| Push-уведомления | Future scope | Можно заменить email или корпоративным каналом |

Вопросы заказчику:

- Должны ли сотрудники создавать обращения с телефона или достаточно просмотра статуса?
- Какие показатели руководитель должен видеть в первый релиз?
- Кто будет менять справочники категорий и SLA?
- Есть ли корпоративный канал уведомлений, который уже используется?

## Задание 3

Примеры уточненных требований:

1. В веб-портале сотрудник должен видеть список своих обращений с номером, темой, текущим статусом и датой последнего изменения.
2. В рабочем месте офицера должна быть очередь обращений с фильтрами по статусу, категории, сроку реакции и ответственному.
3. В веб-дашборде руководитель должен видеть количество открытых обращений, просроченные обращения и распределение по категориям за выбранный период.
4. Система должна отправлять сотруднику уведомление по корпоративной почте при запросе уточнения по обращению.

## Задание 4

Преимущества веб-only MVP:

- проще централизованно обновлять систему;
- меньше платформ и сценариев для разработки и тестирования.

Риски:

- сотрудникам может быть неудобно отвечать на уточнения вне рабочего места;
- если часть пользователей работает преимущественно с мобильных устройств, adoption снизится.

Условия пересмотра:

- бизнес требует реакции сотрудников вне рабочего места;
- политика компании уже предполагает мобильный доступ к внутренним сервисам;
- статистика пилота показывает, что обращения часто требуют быстрых коротких ответов.
