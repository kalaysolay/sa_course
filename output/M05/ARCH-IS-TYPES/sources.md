## Source Boundary

External research is disabled for this topic by the topic passport. The lesson uses a beginner-level practical framing of information system types and does not compare current vendor platforms, mobile frameworks or browser market details.

## Usable Teaching Points

1. The type of information system affects requirements, constraints and acceptance criteria.
2. Web applications are a common default for internal corporate systems because deployment and updates are centralized.
3. Mobile interfaces are useful for short, context-sensitive actions, but are not automatically required for MVP.
4. Desktop applications are still relevant when local files, hardware, isolated networks or workstation-specific constraints matter.
5. Product zones such as employee portal, officer workspace and manager dashboard can be implemented within one technology or split into separate applications.
