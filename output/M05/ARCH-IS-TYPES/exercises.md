# Практика к уроку 23

## Задание 1. Разделите пользовательские зоны

Для проекта Compliance опишите 3-4 пользовательские зоны системы:

- кто работает в зоне;
- какие задачи выполняет;
- какой тип интерфейса подходит;
- почему этот тип интерфейса уместен.

## Задание 2. Определите MVP и future scope

Разделите варианты интерфейсов на две группы:

1. Нужно в MVP.
2. Можно отложить.

Варианты:

- веб-портал сотрудника;
- мобильное приложение сотрудника;
- рабочее место комплаенс-офицера;
- дашборд руководителя;
- десктопный клиент для офицера;
- админка справочников;
- push-уведомления.

Для каждого спорного пункта напишите один вопрос заказчику.

## Задание 3. Перепишите требования с учетом типа системы

Уточните формулировки:

1. "Сотрудник должен видеть свои обращения".
2. "Офицер должен удобно работать с очередью".
3. "Руководитель должен видеть аналитику".
4. "Пользователь должен получать уведомления".

В каждой формулировке укажите интерфейс или канал.

## Задание 4. Найдите риски выбора

Для решения "делаем только веб-приложение, без мобильного приложения в MVP" перечислите:

- 2 преимущества;
- 2 риска;
- 2 условия, при которых решение придется пересмотреть.
