# Проектное задание к уроку 28

Подготовьте черновую входную схему Compliance MVP.

Нужно описать:

1. Единый адрес системы.
2. Какие запросы идут во frontend.
3. Какие запросы идут в backend/API.
4. Где может использоваться health check.
5. Как несколько экземпляров backend могут подключаться к балансировщику.

Схему можно описать текстом:

```text
Browser
  -> Reverse Proxy / Load Balancer
  -> Frontend
  -> Backend instances
  -> Database
```

В конце напишите 3 требования, которые следуют из этой схемы.
