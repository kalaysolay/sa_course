# Практика к уроку 24

## Задание 1. Разложите сценарий по слоям

Возьмите сценарий "сотрудник создает обращение" и заполните таблицу:

| Шаг | Client | Frontend | Backend | Database |
| --- | --- | --- | --- | --- |

Минимально включите:

- ввод данных;
- отправку формы;
- проверку обязательных полей;
- создание обращения;
- возврат номера обращения;
- показ результата пользователю.

## Задание 2. Распределите проверки

Для каждой проверки укажите, где она должна выполняться: frontend, backend или оба слоя.

1. Поле "Описание" обязательно.
2. Сотрудник не может видеть чужие обращения.
3. Файл вложения не должен превышать лимит.
4. Закрытое обращение нельзя редактировать.
5. Дата в фильтре дашборда должна быть корректной.

## Задание 3. Опишите ошибки

Для сценария "офицер запрашивает уточнение" опишите поведение системы при ошибках:

- обращение уже закрыто;
- у офицера нет доступа к обращению;
- backend временно недоступен;
- текст уточнения пустой.

Для каждой ошибки укажите, что видит пользователь и что должна сделать система.

## Задание 4. Нарисуйте базовую схему

В текстовом виде опишите базовую схему Compliance MVP:

```text
... -> ... -> ... -> ...
```

Затем отдельно перечислите внешние компоненты, которые пока не входят в ядро схемы, но могут понадобиться позже.
