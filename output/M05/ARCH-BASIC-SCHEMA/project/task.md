# Проектное задание к уроку 24

Разложите ядро Compliance MVP по схеме:

```text
client -> frontend -> backend -> database
```

Нужно подготовить:

1. Текстовую схему с названиями компонентов.
2. Таблицу ответственности: что делает client, frontend, backend и database.
3. Список минимум из 5 проверок или бизнес-правил с указанием, где они должны выполняться.
4. Список внешних компонентов, которые пока не входят в базовую схему, но могут понадобиться позже.

Ограничение: не добавляйте микросервисы и инфраструктурные компоненты в ядро схемы. Сейчас цель - понять базовые границы ответственности.
