# Сквозной проект Compliance

В этом уроке канонический проектный артефакт не создается и не изменяется. Причина: урок знакомит с архитектурными стилями, но не дает достаточных оснований зафиксировать архитектурный выбор для Compliance.

Практический результат для аналитика - список вопросов о независимых изменениях, владении данными, допустимых задержках и обработке ошибок. Эти вопросы будут использованы в следующих уроках.
