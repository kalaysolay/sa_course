# Project Task

Урок 1 еще не создает канонический артефакт спецификации Compliance-системы. Его задача - научиться смотреть на один и тот же проект разными аналитическими фокусами.

## Практика

Для каждой ситуации выберите один или несколько уместных аналитических фокусов: Business Analyst, System Analyst, Process Analyst, Data Analyst, BI Analyst, Product Analyst.

1. Сотрудники не понимают, в каком статусе находится обращение в комплаенс.
2. Комплаенс-офицеры хотят видеть единую очередь обращений и приоритеты.
3. Руководитель комплаенс хочет дашборд нагрузки отдела.
4. Сотрудники часто бросают форму декларации до отправки.
5. Декларации возвращаются на доработку из-за повторяющихся ошибок.
6. Нужно описать, какие действия доступны сотруднику, комплаенс-офицеру и руководителю.

Для одной ситуации сформулируйте два вопроса: один в фокусе BA, один в фокусе SA.

## Важно

Compliance-проект в курсе - внутренняя система компании. Не трактуйте его как KYC, проверку внешних клиентов или клиентский онбординг.
